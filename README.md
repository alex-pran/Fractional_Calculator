Fractional Calculator

Fractional Calculator is a Python-based calculator project designed to perform mathematical operations with fractions, mixed numbers, and negative values.

The project simulates a button-based calculator interface and processes user input sequentially, similar to a real calculator. It supports addition, subtraction, multiplication, and division while automatically simplifying fractions and displaying results as mixed numbers when appropriate.

Key Features
Perform calculations with fractions and mixed numbers
Support positive and negative numbers
Automatic fraction simplification
Convert improper fractions into mixed numbers
Support sequential calculator-style input
Continue calculations after pressing =
C button to clear the calculator
Backspace functionality
Division-by-zero error handling
Invalid-input and expression validation
Result formatting with both fractional and decimal representations
Technologies
Python
fractions.Fraction
String parsing and validation
Modular functions for input processing and calculation logic
Project Structure

The application is divided into separate functions responsible for:

Parsing fractions and mixed numbers
Tokenizing calculator input
Evaluating mathematical expressions
Formatting calculation results
Processing calculator button input
Handling errors and invalid expressions
Purpose

The main goal of the project is to practice Python programming fundamentals, including functions, conditional logic, exception handling, string processing, and working with built-in Python modules.

The project is also being developed with a future graphical user interface in mind, with the goal of creating a calculator interface similar to a mobile calculator.
